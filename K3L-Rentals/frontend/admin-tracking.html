Active Trip Live Tracking

Consent-based browser GPS location updates for active customer rentals.

📡 Technology Scope & Privacy Disclosures:
  • Method: Voluntary HTML5 browser geolocation shared by customer during active rental.
  • Operating Constraint: Requires active web session. Updates pause when customer device locks, backgrounds browser, or loses mobile signal.
  • Hardware Scope: This represents voluntary web app location telemetry, not dedicated vehicle hardware GPS/OBD-II telematics.
  • Lifecycle Boundary: Telemetry is strictly restricted to active trips (after pickup, before return) and is completely disabled upon trip completion.
